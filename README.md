## 📘 Project Overview
This project was developed as part of the **EvoAstra Internship Assessment**.  
It demonstrates complete **data analysis workflow** on a simulated e-commerce dataset — including **data cleaning, exploratory analysis, revenue insights, and a churn prediction plan**.

The goal of this project is to analyze key business metrics, identify customer behavior patterns, and propose data-driven strategies to improve retention and revenue.

---

## 🧠 Key Objectives
- Understand and classify dataset features  
- Detect and handle data quality issues  
- Perform revenue and customer lifetime value analysis  
- Design a churn prediction model framework  
- Communicate insights effectively through written reports

## 📊 Project Sections
### 🔹 Section A — Data Understanding & Quality
- Classification of variables (numeric, categorical, binary)  
- Identification of missing values, outliers, and incorrect data types  

### 🔹 Section B — Revenue Analysis
- Total revenue and average order value computation  
- Customer Lifetime Value (CLV) estimation  
- Business insights and recommendations  

### 🔹 Section C — Churn Prediction Plan
- Model features: demographics, behavior, engagement metrics  
- Algorithms: Logistic Regression, Random Forest, XGBoost  
- Validation: Stratified K-Fold Cross-Validation  
- Metrics: AUC-ROC, Precision, Recall, F1-Score  

### 🔹 Section D — Communication & Leadership
- Data discrepancy handling (crisis management)  
- Team leadership and collaboration approach
